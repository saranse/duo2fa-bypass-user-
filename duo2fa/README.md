# Duo 2FA Guides

คู่มือการตั้งค่า Duo Unix แยกตามนโยบายและวิธี authentication

## รูปแบบที่มี

- [Bypass User บางบัญชี](bypass-user/): บังคับ Duo กับบัญชีที่เลือก และยกเว้น MFA ให้สมาชิกกลุ่ม `duo-bypass`

## เพิ่มคู่มือในอนาคต

สร้างโฟลเดอร์ใหม่ใต้ `duo2fa/` สำหรับแต่ละรูปแบบ เช่น `ssh-key-mfa/` หรือ `per-user-policy/` พร้อมคู่มือและสคริปต์เฉพาะรูปแบบ
