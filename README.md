# Duo 2FA

คู่มือและสคริปต์สำหรับตั้งค่า Duo Unix บน Linux แบ่งตามรูปแบบการใช้งาน เพื่อเพิ่ม config วิธีอื่นในอนาคตโดยไม่ปะปนกัน

## รูปแบบการตั้งค่า

- [`bypass-user/`](bypass-user/): บังคับ Duo ให้ผู้ใช้ที่กำหนด และยกเว้น MFA ให้บัญชีในกลุ่ม `duo-bypass`

เพิ่มรูปแบบอื่นเป็นโฟลเดอร์แยก เช่น `ssh-key-mfa/` หรือ `per-user-policy/` เมื่อมีคู่มือและสคริปต์สำหรับรูปแบบนั้น
